Transcript provider

Used to fetch timestamped YouTube subtitles. Create a Supadata account and key. Supadata generates the key during onboarding.

AI provider

DeepSeek V4 Flash Supported in this version

YouTube Digest uses DeepSeek V4 Flash for overviews, explanations, translation, and note polishing. Create a DeepSeek API key.

When you use AI features, DeepSeek receives the video transcript and relevant video context. Review DeepSeek's terms and pricing before saving.
Local remix Want to use another AI model? Copy a safe prompt for your coding agent Coding agent ready

This published version supports DeepSeek V4 Flash. You can adapt your own local copy with a coding agent. Before copying, open the exact YouTube Digest project folder that Chrome loaded through Load unpacked in your coding agent. Then expand this section and copy the prompt. For a first-time installation, optional permanent locations include ~/Documents/youtube-digest on macOS or Linux, or %USERPROFILE%\Documents\youtube-digest on Windows. These are suggestions, not assumed paths. Chrome and the extension cannot reliably reveal or copy the actual OS path. Never include API keys in the prompt or chat. Enter them yourself only after the code is ready.
